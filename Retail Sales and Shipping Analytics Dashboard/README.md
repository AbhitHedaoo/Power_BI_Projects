# 📊 Retail Sales and Shipping Analytics Dashboard

## Overview

This project is an interactive Power BI dashboard designed to analyze end-to-end business sales data.
It provides insights into sales performance, customer demographics, and shipping operations.

## Objectives

* Analyze overall sales, cost, and profit
* Understand product and category performance
* Explore regional and demographic trends
* Analyze shipping and logistics performance
* Track business trends over time

## Tools Used

* Power BI
* DAX
* Power Query
* Data Modeling

## Dashboard Sections

* Sales Summary
* Sales Demographics
* Shipping Insights

## Features

* KPI cards for key metrics
* Category and subcategory analysis
* Regional sales breakdown
* Monthly trend analysis
* Shipping performance insights
* Payment method analysis

## Skills Demonstrated

* Data transformation and cleaning
* Data modeling
* DAX calculations
* Multi-page dashboard design
* Business-focused analytics

## How to Use

1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Use filters and visuals to explore insights
