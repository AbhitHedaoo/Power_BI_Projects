# 📊 Facility Management Analytics Dashboard

## Overview

This project is an interactive Power BI dashboard designed to analyze business operations for a facility management company.
It provides insights into services, customers, employees, and overall business performance.

## Objectives

* Monitor overall business performance (sales, cost, profit)
* Analyze service-level performance
* Understand customer distribution and behavior
* Track employee-related metrics and workforce distribution
* Enable data-driven decision making

## Tools Used

* Power BI
* DAX
* Power Query
* Data Modeling

## Dashboard Sections

* Overview (Business KPIs and trends)
* Services Analysis
* Customer Analysis
* Employee Analysis

## Features

* KPI cards for quick insights
* Multi-page dashboard navigation
* Interactive filters and slicers
* Service and customer segmentation
* Employee distribution analysis
* Time-based trend analysis
  
## Skills Demonstrated

* End-to-end dashboard development
* Data transformation and cleaning
* Data modeling and relationships
* DAX calculations and KPIs
* Business-focused analytics

## Data Note

This project was developed for a local client.
For privacy and confidentiality reasons, the original data has been modified and replaced with dummy/sample data.

## How to Use

1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Navigate through different sections and interact with filters
