# 🏏 IPL Analytics Dashboard

## 📊 Overview

This project is an interactive Power BI dashboard designed to analyze sports data.
It focuses on team performance, player statistics, and match-related insights using visualizations.

## 🎯 Objectives

* Analyze team performance and rankings
* Evaluate player statistics
* Explore match-related metrics
* Provide interactive analysis using filters

## 🛠️ Tools Used

* Power BI
* DAX (Data Analysis Expressions)
* Power Query

## 🔍 Features

* Interactive slicers for filtering
* KPI cards for quick insights
* Multiple views (overview, points table, team analysis)
* Clean and structured dashboard design
  
## 🧠 Skills Learned

* Data cleaning and transformation
* Creating DAX measures
* Building data models
* Designing interactive dashboards

## 📚 Learning Source

This project was built by following a tutorial from the Data Tutorial YouTube channel and recreated to practice and understand Power BI concepts.

## 🚀 How to Use

1. Download the `.pbix` file
2. Open it in Power BI Desktop
3. Explore the dashboard using filters

## 📌 Note

This project is created for learning purposes and demonstrates practical implementation of Power BI.
