# 📊 Business Sales Insights Dashboard

## Overview

This project is an interactive Power BI dashboard designed to analyze business sales data.
It provides insights into sales performance across different channels, products, and regions.

## Objectives

* Analyze overall sales, cost, and profit
* Compare performance across sales channels
* Identify top-performing products and categories
* Analyze regional and customer-level data
* Track trends over time

## Tools Used

* Power BI
* DAX
* Power Query
* Data Modeling

## Dashboard Sections

* Internet Sales Analysis
* Reseller Sales Analysis
* Product Sales Analysis

## Features

* Interactive filters (Year, Category)
* KPI cards (Sales, Cost, Profit)
* Category and subcategory breakdown
* Region-wise sales analysis
* Time-based trends (Year, Quarter)
* Customer-level details

## Skills Demonstrated

* Data transformation and cleaning
* Data modeling and relationships
* DAX calculations
* Multi-page dashboard design
* Business-oriented data analysis

## How to Use

1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Use filters to explore insights
